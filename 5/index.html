Part 1: 2D Neural Field Fitting

Network Architecture

I implemented an MLP with positional encoding to map 2D pixel coordinates to RGB colors. The network uses fully connected layers with ReLU activations and positional encoding with L=10 frequency levels. Training used Adam optimizer with learning rate 1e-2.

Hyperparameter Exploration

I tested four different configurations by varying positional encoding (PE) frequency levels (L = 0 vs. L = 10) and network hidden layer width (4 vs. 256). Networks with higher PE frequency (L = 10) can capture fine-grained image details more effectively than those with L = 0. Similarly, wider networks (width = 256) offer greater representational capacity for learning complex color distributions compared to narrow networks (width = 4).

Part 2: 3D Neural Radiance Field

Part 2.1: Create Rays from Cameras

I developed three core transformation functions to generate rays from camera parameters. The transform function applies camera-to-world matrices (obtained from Part 0.3) to convert points from camera space to world coordinates. The pixel_to_camera function uses the intrinsic matrix from camera calibration (Part 0.1) to map 2D pixel coordinates and depth values into 3D camera space by inverting the projection. Finally, pixel_to_ray combines these transformations to generate rays: the ray origin is extracted from the camera-to-world matrix's translation component, while the ray direction is computed by projecting the pixel to world space at unit depth, subtracting the origin, and normalizing.

Part 2.2: Sampling

I implemented a two-stage sampling approach for efficient training. For ray sampling, I created a dataloader that randomly selects N rays per iteration by flattening all pixels across training images, ensuring diverse coverage of the entire dataset. For point sampling along each ray, I uniformly sample 64 positions and add random jitter during training to prevent overfitting to fixed locations. The 3D coordinates are calculated using the parametric equation: x = ray_origin + ray_direction × t, where t represents the sampling distance along the ray.

Part 2.3: Neural Radiance Field

The NeRF model architecture consists of an MLP that takes 3D position x and viewing direction rd as input. Both inputs are encoded with positional encoding (PE) to capture high-frequency details. The network outputs RGB color and volume density σ for each point in 3D space.

NeRF network architecture with positional encoding and skip connections

Part 2.4: Volume Rendering

Volume rendering aggregates the colors and densities along each ray to produce the final pixel color. The rendering equation computes the expected color along ray r:

$$\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i, \text{ where } T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$$

where Ti represents the accumulated transmittance (probability that light reaches point i without being absorbed), (1 - exp(-σiδi)) is the opacity at point i, ci is the RGB color, and δi is the distance between adjacent samples. This formulation allows the network to learn volumetric representations of 3D scenes through differentiable rendering.

Analysis and Observations

During training, the network learned to reconstruct training camera views well, but struggled with validation views. The validation images remained blurry, capturing only faint ArUco tag shapes before failing to converge. This appears to be caused by sparse camera poses in the training set (see Part 0's Camera Pose Visualization). In particular, there were insufficient camera poses from top-down viewing angles. Capturing more diverse data could have improved results, but time constraints prevented recapturing after dismantling the setup.

To maximize performance with limited data, I experimented with various hyperparameters including n_near, n_far, batch size (number of rays), samples per ray, learning rate, learning rate schedule, and network architecture. While these changes did not dramatically improve performance, some adjustments proved helpful:

  • Setting n_near=0.1 and n_far=1.0 after careful calibration using viser visualization
  • Reducing network architecture complexity by decreasing the positional encoding frequency for ray direction from N_dir=6 to N_dir=4

These modifications helped the network progress from completely failing on validation images to at least capturing basic shapes.
