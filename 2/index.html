Project 2: Filters and Edges

This project explores various image filtering techniques, edge detection methods, and their applications in computer vision. We implement convolution operations, edge detection algorithms, and create hybrid images using frequency domain techniques.

Part 1: Filters and Edges

Part 1.1: Convolution Implementation

Implementation of convolution using numpy only, with comparison to scipy.signal.convolve2d. Analysis of runtime performance and boundary handling methods.

Runtime Analysis: [4 for statement] 1.420s, [2 for statement] 0.241s, [scipy] 0.074s

Boundary Handling: I used zero padding to handle the boundary of the image. The default boundary handling method of scipy.signal.convolve2d is 'full', which means the output image is larger than the input image, whereas my implementation corresponds to 'same' which means the output image is the same size as the input image. Also, it use zero padding by default.

Part 1 Bells and Whistles: Gradient Orientations

Computation and visualization of gradient orientations for the cameraman image without using built-in angle functions.

Implementation

Process Explanation: I computed the gradient orientation by using `arctan2(grad_y, grad_x)` to compute the angle of the gradient from the partial derivatives. I then normalized the gradient orientation to the range [0, 1] by using `(orientation + np.pi) / (2 * np.pi)`. I then visualized the gradient orientation by using the formula `hue = (orientation + np.pi) / (2 * np.pi)`, `value = magnitude / magnitude.max()`, and `hsv_to_rgb(hsv)`.

How Unsharp Mask Works

Unsharp Mask Filter Implementation

Explanation: The first naive implementation is just subtracting the blurred image from the original image to get the high frequency component of the image, and then adding it back to the original image to get the sharpened image. The second implementation is using the unsharp mask filter by directly using linear combination of Gaussian filter and the identity filter, which is basically the same as the naive implementation using linearity of convolution, but it is more efficient.

What I learned in this project

I spent a lot of time to debug the code. I encontered many weired bugs, and one of the bugs that took me a lot of time to debug was that the boundary of the masking in blending changes along with the depth of the gaussian stack. After many trials and errors, I found that it was because the kernel size in the gaussian stack changes was even number, so the boundary of the masking changes slightly along with the depth of the gaussian stack. I learned the power of visualizing every component of the code. This project was challenging and exciting, and I really enjoyed it!
